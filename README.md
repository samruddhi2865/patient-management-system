# Patient Management System

This project is a **Patient Management System** developed using **Node.js, Express, EJS, HTML, and CSS**.  
It is a **learning-based project** created to understand how frontend pages interact with a backend server using server-side rendering.

The application demonstrates basic **CRUD operations** (Create, Read, Update, Delete) for managing patient data.

---

## 📌 Project Objective

The main objectives of this project are:
- To learn Node.js and Express framework
- To understand server-side rendering using EJS templates
- To practice HTML and CSS for UI design
- To implement basic CRUD functionality
- To understand project folder structure in Express applications

---

## 🛠️ Technologies Used

- **Node.js** – JavaScript runtime
- **Express.js** – Web framework
- **EJS (Embedded JavaScript)** – Template engine
- **HTML** – Page structure
- **CSS** – Styling and layout
- **JavaScript** – Application logic

---

## ✨ Features

- Add new patient details
- View list of patients
- Edit patient information
- Delete patient records
- Clean and simple UI
- Server-side rendered pages using EJS
